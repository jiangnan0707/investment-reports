二、商业模式与护城河

Anthropic把前沿模型能力通过API、云市场和自有应用销售给企业与个人。API使用量随客户业务增长，Claude Code及Cowork则把调用嵌入员工日常流程。企业工作流越深入，评测、权限、培训和系统集成的迁移成本越高；但模型能力的领先仍需持续研发证明。

竞争判断：OpenAI、Google及开放权重模型分别在产品分发、云生态与成本方面施压。比较应落到同一工作负载的任务成功率、完成成本和可靠性，不能把一次榜单领先外推为永久定价权。巴菲特框架要求观察客户是否愿意长期支付溢价；目前证据支持业务扩张，尚不足以证明永久经济特许权。

十二、综合判断框架

当前证据对 AI 需求强度的支持，高于对 ANT 当前估值的支持。 季度收入和付费大客户增长表明 Claude 能把用量转化成收入；Q3 算力费用增速高于收入，GAAP 经营也由盈转亏。按首日收盘与招股书摊薄股数，约 50 倍的已确认收入倍数要求后续同时兑现增长和经营杠杆。

对台积电等上游标的，Claude 的付费用量与已交付算力比 ANT 的首日涨跌更有解释力。云商自研芯片、第三方加速器、先进封装各自的份额和交付节奏，决定多少模型需求能转为上游订单。组合同时暴露于这两端时，AI 需求与融资条件变化仍可能共同影响估值。

下一次需要改变判断的证据，是连续季度的收入增长伴随费用率下降、现金兑现，以及摊薄后每股权益改善。若算力费用率居高、客户扩张放慢，当前估值对增长误差的容忍度会进一步降低。

十三、数据说明

股本口径。 法律已发行是 7,583,103,996 股 Class A 与 5,636,538,278 股 Class N。后者内含全资子公司持有的 846,840,960 股公益股，会计在外口径扣除这部分，得到 12,372,801,314 股。两种口径均以公开发行和同期私募完成为假设，均排除绿鞋及无经济权益的 Class T、Class F 各 1 股。

摊薄口径。 按 424B4 第 26 页列示的四项合计 18,137,587,873 股，包括 Class A、Class N、库存股法净期权与 RSU，涵盖预计可转票据转换和公益相关发行等。期权扣减按发行价 83 美元测算，本期以固定股数分别乘发行价、首笔成交和收盘价，以便比较。

经营口径。 算力费用率为算力与基础设施费用除以收入，含训练、推理等支出。TTM 收入 352.82 亿美元为 2025Q4 至 2026Q3 四季已确认收入之和。10 月运营年化是近期计费与订阅的估算，公司尚未发布 Q4 确认收入或 Claude 各应用的利润。
