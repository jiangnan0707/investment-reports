二、商业模式

TMDX 把「器官移植」从传统的「冰桶冷藏 + 抢时间」改造为「温热灌注 + 可评估 + 可运输」。收入来自三条绑定在一起的服务：

收入线内容毛利率特征竞争壁垒
OCS 一次性耗材 + 设备灌注套件、一次性泵、传感器（每个器官一副）高（产品毛利率 ~77%）推算FDA 注册 + 专利 + 临床数据
NOP 临床服务外科摘取团队 + 灌注专家 + 器官评估中低（服务毛利率 ~35%）人员培训 + 医院关系
航空物流22 架自有固定翼飞机 + 地面运输低（重资产折旧拖累）自有机队，无人可复制

护城河判断：产品线（OCS 一次性耗材）具备「注册 + 专利 + 临床证据」三重壁垒；物流（自有飞机）是竞争对手 OrganOx、XVIVO 都没有的重资产壁垒；但「服务」部分的壁垒相对薄弱，且拖累整体毛利率。

收入构成正在「向下漂移」

服务收入增速（+28.6%）是产品（+15.7%）的近两倍。这解释了为什么营收在涨、毛利率却在跌——增长最快的那块恰好是最不赚钱的那块。这是本报告贯穿始终的核心矛盾之一。

三、核心指标 — OCS 移植例数

对 TMDX 而言，唯一真正重要的指标是 OCS 移植例数——每一次移植 = 一副高毛利一次性耗材 + 一单 NOP 服务 + 一趟航空物流。营收、利润、渗透率、TAM，全部由此派生。

核心判断：OCS 例数仍在健康增长（约 +17%），但增长的「质量」在恶化——增长越来越依赖单一器官（肝脏），且利润贡献被低毛利的服务/物流稀释。

六、航空机队 — 护城河还是吞金兽？

维度数据
机队规模22 架自有固定翼飞机
NOP 航班覆盖率约 86%（从 61% 提升，飞机数未增 → 利用率提升）
航空相关资产PP&E $365M + 财务租赁 ROU $332M ≈ $697M（占总资产 ~48%）
服务毛利率~35%（航空重资产拖累整体）
资本结构变化财务租赁负债半年 +$348M（杠杆显著抬升）

两种叙事同时成立：

  • 护城河叙事（多方）：自有飞机让 TMDX 能把一颗器官从摘取地运到千里外的受体医院，实现「摘取-灌注-运输」全链路闭环。OrganOx、XVIVO 都没有自有航空，这是重资产、难复制的壁垒。
  • 吞金兽叙事（空方）：飞机 = 巨额固定成本 + 折旧 + 维护，服务毛利率仅 ~35%，且财务租赁把杠杆从 0 拉到 $348M。若移植例数增速放缓，固定成本会反噬利润。

覆盖率 61%→86% 说明利用效率在改善，但「把资产抵押给财务租赁」这一步，本质是公司用资产负债表换现金流——在增长减速的背景下，这是值得警惕的信号。

*FY2025 净利润 $190.3M 含一次性递延所得税资产释放 $82.8M（税前利润 $107.5M + 税收利益 $82.8M）。剔除后「真实」FY2025 净利润约 $107M。

盈利拐点的关键解读：公司 2024 年才首次盈利，2025 年的「巨额盈利」一半靠一次性税收利益，2026 年又主动把营业利润率从 17.9% 压到 12.5–14%。所以「盈利拐点」不是一条向上的直线，而是「账面转正 → 税收助攻 → 主动回调」的复杂路径。真正的盈利质量（营业利润）在 FY2025 触顶后正在回落。

增速与估值匹配

营收增速 82.7% → 37.1% → 23.4%（2026 指引中值）——减速斜率陡峭。以 4.7x P/S 买一个增速快速滑向 20% 区间的公司，安全边际取决于两点：① 肝脏渗透率能否持续爬坡；② 肾脏能否在 2027 打开第二增长曲线。股息率 0%（成长股不派息），融资纪律逻辑（股息 > 融资利率）不适用于本标的。

多空核心分歧

多方逻辑

  1. 需求真实且未被满足：Q2 营收 $189.9M 超预期，指引低端上修，美国移植例数 +17%，说明 OCS 渗透在持续。
  2. 肝脏引擎强劲：+27.7%，渗透率仍只有 19–25%，2028 年 10,000 例 = 近翻倍空间。
  3. 肾脏期权巨大：TAM 翻倍（21K + 10K 例），CMS 全报销，若 2027 临床成功，估值逻辑重估。
  4. 不可复制的护城河：自有 22 架飞机 + FDA 注册 + 临床数据，OrganOx/XVIVO 短期无法复制全链路。
  5. 估值从高位回落：距高点 -42%，P/S 4.7x 已较历史峰值大幅收缩。

空方逻辑

  1. 增收不增利加剧：营收 +20.7% 但净利润 -57.9%，营业利润率指引 16%→12.5–14%，管理层主动压缩利润。
  2. 增长结构单一化：增长全靠肝脏，心脏放缓（+6.5%）、肺萎缩（-41.8%），一旦肝脏渗透放缓，无第二引擎接力。
  3. 投资周期无终点：研发 +98.5%，肾脏两年后才临床，2027 利润率指引缺失，烧钱何时停不可证伪。
  4. 杠杆快速抬升：财务租赁负债半年 +$348M，自由现金流转负，重资产在增长减速时反噬。
  5. 治理/诉讼阴影：Scorpion 做空报告（2025/01）+ 集体诉讼进入证据开示 + 董事衍生诉讼调查（2026/07），治理成本悬而未决。

核心争议焦点

一句话：2026 年 12.5–14% 的营业利润率，是「投资周期的底部」（之后利润率回升、肾脏兑现），还是「结构性下降的开始」（增速滑坡 + 竞争 + 重资产拖累）？

当前局势

TMDX 是「管理层主动用当期利润换长期 TAM 期权」的逆向投资。叙事没变：营收在涨（+20.7%）、例数在涨（+17%）、利润率在缩（-10.7pp）、杠杆在抬（财务租赁 +$348M）。核心问题不是「好不好」，而是「贵不贵、值不值」——4.7x P/S 买一个增速滑向 20%、盈利含金量被一次性税收利益与重资产稀释的公司，需要肾脏这一期权兑现才能支撑。

总结

TMDX 是一家护城河真实、需求真实、但当前处于「用利润换未来」的再投资周期的医疗器械公司。看多它，本质是赌「肝脏渗透 + 肾脏期权」能撑起未来 2–3 年的价值重估；看空它，本质是赌「增速减速 + 重资产杠杆 + 治理阴影」会在期权兑现前先压垮估值。没有确定答案，只有需要被持续跟踪的核心指标。本报告不提供买卖建议，不预测目标价。
