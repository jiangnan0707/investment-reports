二、商业模式

TMDX 把「器官移植」从传统的「冰桶冷藏 + 抢时间」改造为「温热灌注 + 可评估 + 可运输」。收入来自三条绑定在一起的业务：

收入线内容毛利率特征竞争壁垒
OCS 一次性耗材 + 设备灌注套件、一次性泵、传感器、溶液添加剂（每个器官一副）高（产品毛利率 ~77%，推算）FDA/CE 注册 + 专利 + 临床证据（一手 10-K）
NOP 临床服务外科摘取团队 + 灌注专家 + 器官活力评估中低（服务毛利率 ~35%，推算）人员培训体系 + 移植中心关系网络
航空物流22 架自有固定翼飞机 + 地面运输；欧洲通过 PAD Aviation 布局低（重资产折旧/租赁拖累）自有机队，竞品公司无重资产航空能力
护城河判断（巴菲特框架）：产品线具备「注册 + 专利 + 临床证据」三重壁垒，器官级耗材收入具有「剃刀-刀片」式复购特征；自有机队是 OrganOx/XVIVO 都没有的重资产壁垒。但「服务/物流」部分壁垒相对薄弱且稀释毛利率——护城河主要在产品端，而非全链路。需要警惕的是：NRP（常温区域灌注）等替代技术路线正在医学界挑战 OCS 的增量价值（见第七节），护城河的「宽度」并非没有争议。

护城河叙事

  • 自有飞机实现「摘取-灌注-运输」全链路闭环，OrganOx/XVIVO 短期无法复制
  • 覆盖率 61%→86% 说明单机效率在改善，重资产的固定成本正在被摊薄
  • PAD Aviation 是欧洲器官空运网络第一步，把美国的成功模式输出到欧洲（2028 年后第二地理曲线）
  • 物流收入 +39%，需求真实且放量

吞金兽叙事

  • 飞机 = 固定成本 + 折旧 + 维护 + 飞行员培训，服务毛利率仅 ~35%
  • 财务租赁负债半年 +$348M——用资产负债表换现金流，FCF 转负
  • 利息支出同比翻倍（$3.5M → $7.2M/季），利润表已在付代价
  • 若例数增速放缓，固定成本反噬；PAD 并表初期继续稀释利润率
净债务口径修正（重要）：上期报告「净债务 -$21M」仅计现金减可转债，未计入财务租赁。本期修正：有息负债合计 ≈ 可转债 $454.3M + 长短期借款 $59.7M + 财务租赁 $347.7M ≈ $862M（一手），现金 $472.7M → 净债务约 $389M（推算；若剔除租赁则为净现金 +$18M）。企业价值 EV ≈ $2.93B + $0.39B ≈ $3.32B（推算）。

公司对策：ENHANCE 试验 + CHOPS

ENHANCE Heart（下一代 OCS）

  • 2026/02/09 获 FDA 全额无条件 IDE 批准——公司称首个随机对照盲法供心保存试验
  • Part B 直接对标 cold static storage，目标是证明优效性（而非非劣效）
  • Part A 预计 2026 年内完成、Part B 2027 年初启动；若成功，重新定义心脏市场标准

CHOPS（2026/04 推出）

  • Controlled Hypothermic Organ Preservation System——主动低温保存设备
  • 用作 ENHANCE / DENOVO 试验的对照臂，摆脱对竞品设备做对照的依赖
  • 市场一度困惑其与 OCS 的定位关系（Q1 电话会）——既是对冲也是自我竞争的风险

支付端（CMS/Medicare）

2026 年未搜到针对 OCS 的 NTAP/DRG 不利变更（时效性已核查）。结构性背景：NTAP 最长 3 年，OCS 早期 NTAP 已自然到期，现在主要依赖 DRG 打包报销与移植中心支付；公司 10-Q 风险因素持续披露对少数大客户与支付方教育的依赖。管理层认为 CMS 对心/肺/肝 OCS 一贯支持，正争取肾脏纳入标准器官获取规则（100% 覆盖预期）。

多空核心分歧

多方逻辑

  1. 需求真实且未被满足：Q2 营收创纪录 $189.9M（+21%），指引低端上修；肝渗透率仅 36%，2028 年 10,000 例 = 近翻倍空间
  2. 利润率是「主动压缩」而非恶化：Q1 7.6% → Q2 12.5% 环比修复 4.9pp；研发增量几乎全是可收缩的外部开支（咨询 +459%），投资周期一旦结束，利润率修复弹性大
  3. 肾脏期权巨大：TAM 翻倍（21K + 10K 例），单例 $40-45K，CMS 预期全报销；2027 初提交 IDE 节奏明确
  4. 竞争验证行业价值：Terumo $15 亿收购 OrganOx——器官灌注赛道获产业资本定价；TMDX 是唯一有全链路（产品+服务+航空）的公司
  5. 资产负债表仍厚：现金 $472.7M，可转债 2028 年才到期；空头兴趣从 35% 降至 24%，拥挤度改善
  6. ENHANCE 优效设计：若 Part B 证明 OCS 对冷藏优效，心脏市场（当前仅 +6.5%）重新点火

空方逻辑

  1. 增收不增利已持续两季：EPS 连续 miss（Q1 $0.30 vs $0.62；Q2 $0.44 vs $0.50），营业利润率指引从 16% 一路下调至 12.5-14%
  2. 增长结构单一化：近 8 成收入靠肝脏，心脏 +6.5%、肺 -42%；肝脏渗透到 36% 后基数效应显现，增速将自然回落
  3. 需求端分母收缩：美国遗体捐献者 -2.5%（十多年首降）+ Transplant Modernization Act 扰动——行业 TAM 的分母出现拐点信号
  4. 技术路线被挑战：NRP 生存数据与 OCS 相近且成本更低（Duke/TCTMD）；XVIVO DCD 心脏 IDE 获批；Terumo 入场后肝脏竞争升级
  5. 杠杆快速抬升：财务租赁半年 +$348M、FCF 转负、利息支出翻倍；净债务（含租赁）约 $389M
  6. 治理阴影未散：集体诉讼 2026/07/21 被部分驳回撤诉动议、进入 discovery；8 月再添律所衍生调查；CEO 之妹执掌肺项目（关联交易已披露）
  7. 2027 无指引：管理层拒绝给 2027 利润率可见度——投资周期何时结束不可证伪

总结

TMDX 是一家护城河真实、需求真实、但当前处于「用利润换未来」再投资周期的医疗器械公司。看多它，本质是赌「肝脏渗透 + 肾脏期权 + ENHANCE 优效」能撑起未来 2-3 年的价值重估；看空它，本质是赌「增速减速 + NRP/巨头竞争 + 重资产杠杆 + 供体拐点」会在期权兑现前先压垮估值。与上期相比，本期新增的两个变量——Terumo 入场带来的竞争升级与供体分母首次收缩——都偏向空方；而空头回补与利润率环比修复偏向多方。没有确定答案，只有需要被持续跟踪的裁决指标。本报告不提供买卖建议，不预测目标价。
