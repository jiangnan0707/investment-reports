一、上次报告（09-21）以来发生了什么

过去 7 天跨越了中秋（9/25）。上份报告设下的"批价裁决线"迎来首轮验卷：价格端读数好于预期——媒体调研称飞天批价"坚挺超预期"、终端零售均价连续九天稳在 1800 元上方；但量的信号明显分化——白酒整体"旺季不旺"、有酒商称销量同比降一半，全行业"少卖约 10%、库存快见底"。价格与销量走向了两个方向，市场用词总结为三个字："价在量先"。

三、商业模式

怎么赚钱：一瓶酒的品牌定价权

贵州茅台卖的是茅台酒（飞天/生肖/精品/年份酒等）和系列酒（茅台1935、王子、迎宾等）。核心利润来自茅台酒：2026 H1 茅台酒收入 777.24 亿（占比 85.7%），毛利率高达 93.5%；系列酒 129.34 亿（占比 14.3%），毛利率约 76%。赚钱的本质是"品牌溢价 + 稀缺供给"——同样的高粱小麦，茅台能卖出几倍于竞品的价格。

护城河：巴菲特式"经济特许权"的教科书样本

  • 品牌定价权（最强护城河）：2026 年在白酒行业整体降价、奢侈品全球降价的背景下，茅台年内已六度调价（自营店 9-08 提至 1766 元为第六次），飞天出厂价年内两次上调（1169→1269→1369）。中秋验证结果进一步坐实：全行业"旺季不旺"之下，飞天是唯一终端价格坚挺的大单品，且"双节前夕批价上涨"——定价权仍在的直接验证。
  • 工艺 + 环境壁垒：茅台镇 7.5 平方公里核心产区、12987 工艺、5 年陈酿期——产能扩张受地理和时间的硬约束，竞争对手无法快速复制。
  • 渠道体系收权进入"收官阶段"："4+6"渠道体系（i茅台+自营+经销+商超等）跑通后，公司开始用限购而非放量来管理供需——9-17 新政（个人年购上限 5 箱）9-22 起进入执行落地期（21 财经报道自营店规则更新），既保 C 端公平抢购体验，又防黄牛套利。董事长中秋前暗访专卖店喊话"别做黄牛"、Costco 上海店万瓶飞天再售罄——供需紧平衡的官方口径与市场端证据互相咬合。

本报告的重点商业模式观察："价在量先"正是消费品化改革想要的结果。金融品逻辑下放量收钱（黄牛加价是厂商的"隐性补贴"），消费品逻辑下控量保体验（让真实消费者以官方价买到 = 品牌长期心智投资）。中秋验卷显示：量的收缩（全行业少卖约 10%）没有拖垮价格，反而因库存见底让价格信号更干净。短期牺牲渠道弹性（经销商利润收窄、大商分流资金去黄酒），长期把定价权 100% 收归官方。

四、核心指标 — 出厂价/批价 + 股息率

中秋验证的核心结论：茅台的"价在量先"是改革想要的结果——价格由官方锚定、销量让给真实开瓶需求，黄牛与囤货盘被挤出。但这同时意味着报表的弹性收窄：量的收缩（行业 -10% 左右）会压收入，价的坚挺保住的是利润率和定价权。三季报大概率是"营收降幅收窄、净利仍微降"的组合，而非市场幻想的 V 型反转。

行业坐标：板块普跌中的结构性韧性

中秋反馈的分化结构：全行业"少卖约 10%、库存快见底"（三方 雪球热帖），次高端送礼价位下沉至 200–700 元；茅台同期跌幅显著小于同行（9 月同行月跌 20–31% vs 茅台约 -4.4%，二手）。值得记录的渠道信号：茅台、五粮液的大商在集体拥抱黄酒（9-21 澎湃报道）——经销商资金在行业见底前先行多元化，这与"去库存尾声"并不矛盾：大商先于酒厂转型，恰恰是上一轮 2013-2015 出清的剧本重演。

茅台为本土消费公司、无跨境收入敞口，本节只写政策风险，不展开地缘政治。

风险项现状（含阶段）影响强度

传导强度排序一句话：公务消费管控（存量收缩，已充分定价）> 消费税改革传闻（无时间表、未落地）> 国资动作（当前为正向承接）。监测清单：① 消费税征收环节后移的立法阶段信号；② 政务禁酒执行细则是否有扩围；③ i茅台/自营政策变化（限购、调价、投放）；④ 国庆后批价与渠道政策联动。

  • 白酒板块情绪冰点（同行月跌 20-30%），茅台难以独善其身

九、多空核心分歧

多方论据

  1. 中秋首轮验卷通过（价格端）：媒体调研称飞天批价"坚挺超预期"、零售均价连续九天 1800 上方——官方控量没有被节后抛压击穿，"控量挺价"论获得旺季实测支持。
  2. "价在量先"正是改革目标：渠道去库存接近尾声（"少卖 10% 但库存快见底"），量缩价稳 = 消费品化的预期路径，而非需求崩塌。
  3. 相对估值极低：PE 19.1x ≈ 历史 10% 分位，同行月跌 20-30% 背景下茅台跌幅最小，机构"逢低增配"首选。
  4. 段永平再度买入 3 万股：标志性的"越跌越买"信号（约 3692 万元），聪明钱在 1230 一带公开表态（情绪信号，非基本面证据）。
  5. 杠杆资金持续回流：融资余额从 9-18 的 171.18 亿回升至 172.26 亿（9-24）。

空方论据

  1. "旺季不旺"是行业事实：白酒整体少卖约 10%、有酒商称销量同比降一半、送礼价位下移至 200-700 元——茅台的坚挺是份额转移，行业总盘子仍在收缩。
  2. "价在量先"不可持续：价格坚挺部分来自官方控量（限购）而非需求扩张；若国庆动销继续走弱，价盘独木难支。
  3. 报表仍未验证：动销/批价是渠道口径，Q2 双降（营收 -5.23%/净利 -6.90%）是报表事实——传导成立与否，10 月下旬三季报见分晓。
  4. 需求结构下沉：送礼价位集中 200–700 元、次高端需求下沉，飞天"独坚"依赖收藏与礼赠属性，节后回流风险真实存在。
  5. 渠道信心未修复："酒商不敢再赌节后能卖掉"、大商集体拥抱黄酒——渠道资金正在用脚投票，转型窗口期被同行分流。
  6. 长期结构性逆风未变：政商务宴请收缩、代际饮酒习惯变迁，市场对这两条给的是"永久折价"而非"周期折价"。
核心争议焦点："价在量先"到底是消费品化的成功（官方精准控量 + 真实开瓶需求托底）还是需求坍缩前的最后一道防线？
裁决指标（已进入第二轮计时）：① 国庆（10/1–10/8）节后两周，散瓶批价能否稳在 1700 元以上（跌破 1650 = 转型遇阻；中秋首轮定性通过，但日度数字未获一手验证）；② 10 月下旬三季报营收/净利能否转正或显著收窄降幅；③ 节后社会库存回流量（回收商报价是先行指标）。

十一、雪球 / 散户讨论

中秋后一周，散户侧的事件头条是段永平的公开加仓——它把"越跌越买"从论坛口头禅变成了有金额、有股数的公开动作：

  • 段永平再度买入 3 万股（约 3692 万元，≈1231 元/股）：9-28 多平台报道其发帖"再度买入贵州茅台 3 万股"，"践行越跌越买"；当日贵州茅台盘中翻红。三方 段永平长期持有茅台，此次为公开发帖的再度买入——金额对其体量而言是信号意义大于仓位意义，但"价值投资旗手在 1240 一带公开出手"本身改变了散户情绪的锚。
  • 去库存叙事走红：雪球热帖"白酒少卖 10%，库存却快见底了"（9-26）与券商"中秋反馈平稳"形成互证——散户讨论的焦点从"社会库存何时爆"转向"库存见底后谁来补库"。
  • 情绪结构：散户悲观（"清算派"帖子仍热）vs 段永平式"越跌越买"的对撞在节后首日集中上演。历史上这种"标志性个人投资者公开加仓 + 散户情绪极端化"的组合多出现在底部区域，但无法据此判断时点。

三方 社区观点情绪化、样本有偏，仅作市场情绪参考，不构成事实依据。段永平买入金额约 3692 万元（约 3 万股，折合约 1231 元/股）为三方转述口径，未见一手披露。
