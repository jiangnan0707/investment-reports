二、商业模式

泡泡玛特是一家以 IP 为核心、以盲盒/手办/毛绒为载体、全球化运营的潮流玩具公司。商业模式可拆为「上游 IP 孵化 → 中游产品化与供应链 → 下游全渠道销售 → 会员复购」四层。

怎么赚钱

  • 艺术家 IP 授权/买断：签约或买断艺术家 IP（LABUBU 作者龙家升、MOLLY 作者 Kenny Wong 等），占总收入约 90%；
  • 产品化变现：把 IP 做成盲盒、手办、毛绒、积木等，盲盒定价 69–159 元/只，H1 毛利率 69.7%一手；
  • 毛绒产品崛起：2026 H1 毛绒收入 98.25 亿元（同比 +60%），已占总收入 57.2%，从「盲盒」单点向「多品类」延伸一手；
  • 全渠道销售：线下 676 家门店 + 2,827 台机器人商店，线上自有 APP/官网 + 抖音/天猫 + Amazon 等第三方平台；
  • 会员体系：全球累计注册会员超 1 亿人，中国内地会员 8,244 万，会员贡献销售额占中国内地收入 92.9%，复购率 51.6%一手。

护城河（费雪/巴菲特框架）

  • IP 心智 + 情感联结：消费者为「情感+收藏」付费而非功能，IP 是无形资产护城河；
  • 艺术家中台 + 供应链快反：从设计到上架周期短，能持续孵化新 IP，11 个 IP 收入过亿（vs 2025 全年更少），矩阵显著加宽；
  • 规模 + 渠道密度：全球 3,000+ 触点、全球化采购与仓储，是后发者难以复制的运营壁垒；
  • 第一条软肋：IP 热度有生命周期，单 IP 热度衰减风险由「矩阵化」对冲——本版证据：LABUBU 占比从 38.1% 降至 25.9%，星星人补位。

把泡泡玛特从「不错的中国玩家」升级为「全球化平台」的叙事，是 2024–2025 年估值狂飙（PE 一度 80x+）的核心引擎。本期中报第一次对这个叙事证伪了一半。

怎么解读「海外 -11.1%」

  • 不是全面溃败，是「线上」崩了：海外零售店仍 +20.8%（线下体验抗跌），但海外线上 -44.0%（25.61 亿 → 14.33 亿），直接拖垮分部。贸易应收款同步下降（线上平台收入降低）印证了这一点。
  • 三个可能原因（官方未明说，此处为推断推算）：① 2025 年 TikTok Shop/Shopee 等海外直播电商的高基数退潮；② LABUBU 海外热度在 2025 年集中爆发后的自然回落；③ 人民币升值 + 关税/物流成本侵蚀海外电商毛利，公司主动收缩低效渠道。
  • 海外利润率斜率恶化：海外分部利润率从 44.1% 跌到 30.3%，比收入下滑更刺眼——高毛利海外生意正在「变贵变难」。
  • 但中国业务接棒了：中国 +47.3%（线上 +62.7%）是意外之喜，说明内需消费 + 会员复购（51.6%）有韧性，中国业务利润率升至 53.0%。
一句话：市场 2025 年给的是「全球化平台 + 海外高增长」的估值，本期中报证明海外是「高波动、高基数、高汇率敏感」而非稳定引擎。估值从 80x 杀到 14x，本质是把这个「海外成长期权」重新定价。

六、IP 矩阵与生命周期

从「单爆款」到「矩阵」的意义

潮玩公司的宿命是 IP 生命周期：单个 IP 会经历「孵化—爆发—成熟—衰退」。泡泡玛特历史上经历过 MOLLY（2019）→ SKULLPANDA/DIMOO（2021）→ LABUBU（2024–25）的接力。2026 H1 第一次出现「双核」（LABUBU 25.9% + 星星人 15.4%）+ 5 个 9–10% 的第二梯队 + 11 个过亿 IP的格局，这对「单点失败」风险的分散是实打实的进步。

但生命周期风险仍在

  • LABUBU 是否已过顶？占比从 38.1% 降到 25.9%，可能意味着 LABUBU 绝对体量已见顶回落（星星人等补位掩盖了总量）。需 H2 观察 LABUBU 绝对收入是否环比下滑。
  • 星星人是「下一个 LABUBU」还是「流星」？半年 26.5 亿的爆发速度堪比当年的 LABUBU，但爆发型 IP 的持续性存疑。
  • 毛绒 +60% 是品类红利还是透支？毛绒占据 57.2% 收入，高度依赖「搪胶毛绒挂件」这一品类，若品类热度退潮，风险集中。

—— 这也是「费雪 15 要点」里最难回答的一条：公司的增长是否依赖少数明星 IP 的运气，还是拥有可复制的孵化机制？ 2026 H1 的证据偏向后者，但需要用更长时间来认证。

多方：14x 是「错杀」

  • 中国业务 +47.3% 重新加速，内需基本盘超预期；
  • IP 矩阵去单点化（LABUBU 38%→26%），平台化逻辑兑现；
  • 124 亿净现金 + 17.44 亿港元回购托底；
  • PEG（营收口径）仅 0.6，23.8% 的营收增速配 14x 不贵。

空方：14x 是「价值陷阱」

  • 利润增速只有 +10%，PEG（利润口径）1.4，属于合理偏贵；
  • 海外引擎转负（-11.1%），全球化叙事证伪中；
  • 存货周转 123→201 天，警惕 H2 减值；
  • 超级成长股一旦失速，估值可长期停在 10–15x，无「均值回归」保障。

核心争议焦点

海外业务是中国/全球化的「成长期权」还是「伪命题」？多方认为 -11.1% 是高基数 + 汇率的一次性扰动，零售店仍 +20.8% 证明海外消费力仍在；空方认为线上 -44% 是 LABUBU 海外热度退潮的领先指标，H2 可能传导到线下。

裁决指标（下一份财报看什么）

  • 海外分部收入能否环比/同比转正（尤其是线上渠道）——决定全球化叙事是否可证伪修复；
  • LABUBU 绝对收入是否见顶回落——决定单 IP 生命周期判断；
  • 存货周转天数能否从 201 天回落——决定「前置备货」解释是否成立；
  • 毛利率能否守住 69% 一线——决定利润弹性能否恢复。

总结

2026 中报是泡泡玛特「成长叙事」的一次分水岭式验证：营收增速从 +184.7% 落回 +23.8%，海外业务首次转负（-11.1%，线上 -44%），把一个「超级成长股」打回「常规快速成长股」。但硬币的另一面是基本盘质量在变好——中国 +47.3%（线上 +62.7%）重新加速、IP 矩阵去单点化（LABUBU 38%→26%、星星人补位）、零负债 + 124 亿现金 + 17 亿回购。

对投资者的核心追问是：14x PE 是否已把「增长换挡 + 海外失速」充分定价？多方看到的是「错杀」（PEG 营收口径 0.6 + 内需加速 + IP 平台化）；空方看到的是「价值陷阱」（利润增速 10% + 海外证伪 + 存货 201 天）。裁决权在 H2 的海外收入与存货两个数据上——在那之前，这是一只「赔率已改善、确定性待验证」的标的，而非「无脑捡便宜」。
