二、商业模式

泡泡玛特是一家以 IP 为核心、以盲盒/手办/毛绒为载体、全球化运营的潮流玩具公司。商业模式可拆为「上游 IP 孵化 → 中游产品化与供应链 → 下游全渠道销售 → 会员复购」四层。

怎么赚钱

  • 艺术家 IP 授权/买断：签约或买断艺术家 IP（LABUBU 作者龙家升、MOLLY 作者 Kenny Wong 等），授权 IP 占总收入约 90%；
  • 产品化变现：把 IP 做成盲盒、手办、毛绒、积木等，H1 毛利率 69.7%一手；
  • 毛绒产品崛起：2026 H1 毛绒收入 98.25 亿元，已占总收入 57.2%，从「盲盒」单点向「多品类」延伸；
  • 全渠道销售：线下 676 家门店 + 2,827 台机器人商店，线上自有 APP/官网 + 抖音/天猫 + Amazon/AliExpress 等第三方平台；
  • 会员体系：全球累计注册会员超 1 亿人，中国内地会员 8,244 万，会员贡献销售额占中国内地收入 92.9%，复购率 51.6%一手。

护城河（费雪/巴菲特框架）

  • IP 心智 + 情感联结：消费者为「情感+收藏」付费而非功能，IP 是无形资产护城河；
  • 艺术家中台 + 供应链快反：11 个 IP 收入过亿、6 大 IP 营收破 10 亿，矩阵持续加宽——本版最新证据：星星人 26.5 亿跃升第二大 IP，LABUBU 占比降至 26%；
  • 规模 + 渠道密度：全球 3,000+ 触点、全球化采购与仓储，是后发者难以复制的运营壁垒；
  • 软肋（本版最需正视）：IP 热度有生命周期。LABUBU 复古理发店系列（6 月）常规款上线半小时跌破发售价，与星星人隐藏款溢价 13 倍形成鲜明分化——「全系溢价」的时代已结束，热度从「普涨」转向「结构性」二手。

三、2026 中期业绩解读（财务主体）

⚠ 中报核心结论（不变）：营收增速从 2025 全年 +184.7% 骤降至 +23.8%；且大幅低于卖方一致预期——营收 171.73 亿 vs 市场预估 199.8 亿（miss 约 -14%），净利 50.38 亿 vs 预估 66.4 亿（miss 约 -24%）二手。高盛口径：收入低于其预期约 10%、经调整纯利低于预期 13%，内地市场亦略逊。同时出现「中国业务加速（+47.3%） / 海外业务转负（-11.1%）」的结构性背离。这是估值中枢从 80x+ 杀到 14x 的根本原因。

三个被财报「藏起来」的关键信号

  • ① 增长换挡是「减速带」不是「拐头」：营收 +23.8% 仍属高速，但相较 2025 全年 +184.7%（含 LABUBU 爆发的低基数效应）是断崖式回落。市场要重新定价的，是从「超级成长股」回归「常规快速成长股」的估值锚。
  • ② 归母净利增速（+10.1%）显著低于营收增速（+23.8%）：利润弹性消失，主因毛利率下滑（69.7%）+ 汇兑损失 7.20 亿元（人民币升值侵蚀海外利润，H1'25 为汇兑收益 +1.20 亿）。「其他亏损净额」由 -1.79 亿扩大到 -6.89 亿。
  • ③ 无中期股息 + 启动 20–50 亿回购：董事会不建议派付 2026 中期股息；同时王宁在业绩会宣布未来 6 个月启动不低于 20 亿、不高于 50 亿元的股份回购计划二手。公司把现金回报从「分红」转向「回购」，对融资纪律型投资者（股息率 > 融资利率）不友好——但港股不使用融资，故此处仅作股东回报方式变化的观察，不构成买入逻辑。

怎么解读「海外 -11.1%」

  • 不是全面溃败，是「线上」崩了：海外零售店仍 +20.8%（线下体验抗跌），但海外线上 -44.0%（25.61 亿 → 14.33 亿）直接拖垮分部。CNBC 报道印证：亚太（除中国）与美洲收入双双下滑二手。
  • 花旗的归因：业绩低于其预期，除海外疲弱外，还点名库存管理、供应链、仓储物流、门店运营等多重经营逆风；并转述管理层态度——年初定下的 2026 全年营收 +20% 目标「已难以达成」，王宁在业绩会上亦承认此前 20% 目标面临挑战，花旗据此把 2026 集团营收预测下调为同比 -8%二手（意味着 H2 营收同比降幅比 H1 更深，是当前最悲观的卖方假设之一）。
  • 美银更激进：评级降至「中性」，目标价大幅下调 43% 至 170 元，指 LABUBU 在欧美热潮降温 + 利润率压力；对今明两年经调整 EPS 预测分别下调 19%/26%二手。
  • 海外利润率斜率恶化：分部利润率从 44.1% 跌到 30.3%，比收入下滑更刺眼——高毛利海外生意正在「变贵变难」。
  • 但中国业务接棒了：中国 +47.3%（线上 +62.7%）是意外之喜，内需消费 + 会员复购（51.6%）有韧性，中国利润率升至 53.0%。
一句话：市场 2025 年给的是「全球化平台 + 海外高增长」的估值，本期中报证明海外是「高波动、高基数、高汇率敏感」而非稳定引擎。估值从 80x 杀到 14x，本质是把这个「海外成长期权」重新定价。分歧全在 H2。

  • 风险提示（马克斯第二层思维）：「跌不动」≠「跌完了」。9/10 单日 -2.18% + 沽空占比冲上 32%（见下节）说明空头并未撤退，而是在箱体内反复施压。若 H2 海外线上继续 -40% 或存货减值落地，箱体下沿 150 之下，下一个心理关口是 140.10（52 周低点）。
一句话：三周的价格行为，是市场对「增长换挡 + 海外失速」的定价从恐慌进入僵持——140 的恐慌盘被吸收，估值锚稳定在 14x，但 150–158 的箱体既上不去也下不来。方向选择只能由 H2 的海外收入和存货数据给出。

总结

2026 中报是泡泡玛特「成长叙事」的一次分水岭式验证：营收增速从 +184.7% 落回 +23.8%（且 miss 市场预期 14%），海外业务首次转负（-11.1%，线上 -44%），管理层放弃全年 +20% 目标，把一个「超级成长股」打回「常规快速成长股」。中报后三周的价格行为（140 恐慌低点 → 150–158 箱体、缩量至 1/8 以下）表明第一次定价已经完成：卖方集体转谨慎（美银/野村降中性，花旗降目标价 198 并预测全年营收 -8%），但没有一家给出卖出评级。

本版新增的两个信号值得重视：① 港交所 9/1《证券变动月报表》显示 8 月已发生回购注销，与 20–50 亿回购计划对应，管理层用真金白银在 150 港元附近表态；② 沽空占成交比例升至 32.16%，创近年高位，专业机构在做空这只「利空出尽」的股票。这是一个回购盘与沽空盘在箱体内直接对垒的格局。

硬币的另一面是基本盘质量在变好——中国 +47.3%（线上 +62.7%）重新加速、IP 矩阵去单点化（LABUBU 38%→26%、星星人 +580%）、零负债 + 124 亿现金 + 20–50 亿回购，段永平 5.55% 的重仓仍在。但同样必须承认：LABUBU 收入首次同比转负，头号 IP 见顶的迹象第一次以数字形式出现。

对投资者的核心追问是：14.4x PE 是否已把「增长换挡 + 海外失速」充分定价？多方看到的是「错杀」（中报利空三周消化完毕 + 内需加速 + IP 平台化 + 回购托底）；空方看到的是「价值陷阱」（花旗 -8% 全年预测 + LABUBU 转负 + 存货 201 天 + 沽空 32%）。裁决权在 H2 的海外收入与存货两个数据上——在那之前，这是一只「赔率已改善、确定性待验证」的标的，而非「无脑捡便宜」。箱体何时被打破，就是答案揭晓的时刻。
