二、商业模式

泡泡玛特是一家以 IP 为核心、以盲盒/手办/毛绒为载体、全球化运营的潮流玩具公司。商业模式可拆为「上游 IP 孵化 → 中游产品化与供应链 → 下游全渠道销售 → 会员复购」四层。

怎么赚钱

  • 艺术家 IP 授权/买断：签约或买断艺术家 IP（LABUBU 作者龙家升、MOLLY 作者 Kenny Wong 等），授权 IP 占总收入约 90%；
  • 产品化变现：把 IP 做成盲盒、手办、毛绒、积木等，H1 毛利率 69.7%一手；
  • 毛绒产品崛起：2026 H1 毛绒收入 98.25 亿元（同比 +60%），已占总收入 57.2%，从「盲盒」单点向「多品类」延伸一手；
  • 全渠道销售：线下 676 家门店 + 2,827 台机器人商店，线上自有 APP/官网 + 抖音/天猫 + Amazon 等第三方平台；
  • 会员体系：全球累计注册会员超 1 亿人，中国内地会员 8,244 万，会员贡献销售额占中国内地收入 92.9%，复购率 51.6%一手。

护城河（费雪/巴菲特框架）

  • IP 心智 + 情感联结：消费者为「情感+收藏」付费而非功能，IP 是无形资产护城河。最新证据：星星人「动物农场」8/20 晚 10 点发售即秒罄，得物预约超 2.4 万人，隐藏款「不丑小鸭」二手价从 129 元炒至 1,799 元（溢价近 13–14 倍）二手——需求端热度仍在；
  • 艺术家中台 + 供应链快反：11 个 IP 收入过亿、6 大 IP 营收破 10 亿，矩阵持续加宽；
  • 规模 + 渠道密度：全球 3,000+ 触点、全球化采购与仓储，是后发者难以复制的运营壁垒；
  • 软肋：IP 热度有生命周期，单 IP 热度衰减风险由「矩阵化」对冲——本版证据：LABUBU 占比从 38.1% 降至 25.9%，星星人（+580.6%）补位成第二核。

三、2026 中期业绩解读（财务主体）

⚠ 中报核心结论（与 8/21 版一致，本版补充预期差量化）：营收增速从 2025 全年 +184.7% 骤降至 +23.8%；且大幅低于卖方一致预期——营收 171.73 亿 vs 市场预估 199.8 亿（miss 约 -14%），净利 50.38 亿 vs 预估 66.4 亿（miss 约 -24%）二手。同时出现「中国业务加速（+47.3%） / 海外业务转负（-11.1%）」的结构性背离。这是估值中枢从 80x+ 杀到 14x 的根本原因。

三个被财报「藏起来」的关键信号

  • ① 增长换挡是「减速带」不是「拐头」：营收 +23.8% 仍属高速，但相较 2025 全年 +184.7%（含 LABUBU 爆发的低基数效应）是断崖式回落。市场要重新定价的，是从「超级成长股」回归「常规快速成长股」的估值锚。

六、海外扩张拆解（本期最大利空）

把泡泡玛特从「不错的中国玩家」升级为「全球化平台」的叙事，是 2024–2025 年估值狂飙（PE 一度 80x+）的核心引擎。本期中报第一次对这个叙事证伪了一半。中报后中国（含港澳台及海外华人渠道口径调整后）收入占比已升至约 71%二手，「海外狂飙」阶段性告一段落。

怎么解读「海外 -11.1%」

  • 不是全面溃败，是「线上」崩了：海外零售店仍 +20.8%（线下体验抗跌），但海外线上 -44.0%（25.61 亿 → 14.33 亿）直接拖垮分部。CNBC 报道印证：亚太（除中国）与美洲收入双双下滑二手。
  • 花旗的归因（8/21）：业绩低于其预期，除海外疲弱外，还点名库存管理、供应链、仓储物流、门店运营等多重经营逆风；并转述管理层态度——年初定下的 2026 全年营收 +20% 目标「已难以达成」，花旗据此把 2026 集团营收预测下调为同比 -8%二手（注意：这意味着花旗预期 H2 营收同比降幅比 H1 更深，是当前最悲观的卖方假设之一）。
  • 三个原因（官方未完全明说，部分为推断推算）：① 2025 年 TikTok Shop/Shopee 等海外直播电商高基数退潮；② LABUBU 海外热度 2025 年集中爆发后自然回落；③ 人民币升值 + 关税/物流成本侵蚀海外电商毛利。
  • 海外利润率斜率恶化：分部利润率从 44.1% 跌到 30.3%，比收入下滑更刺眼——高毛利海外生意正在「变贵变难」。
  • 但中国业务接棒了：中国 +47.3%（线上 +62.7%）是意外之喜，内需消费 + 会员复购（51.6%）有韧性，中国利润率升至 53.0%。
一句话：市场 2025 年给的是「全球化平台 + 海外高增长」的估值，本期中报证明海外是「高波动、高基数、高汇率敏感」而非稳定引擎。估值从 80x 杀到 14x，本质是把这个「海外成长期权」重新定价。花旗 -8% 的全年假设若兑现，14x 也不便宜；若 H2 海外企稳，14x 就是错杀——分歧全在 H2。

总结

2026 中报是泡泡玛特「成长叙事」的一次分水岭式验证：营收增速从 +184.7% 落回 +23.8%（且 miss 市场预期 14%），海外业务首次转负（-11.1%，线上 -44%），管理层放弃全年 +20% 目标，把一个「超级成长股」打回「常规快速成长股」。中报后两周的价格行为（140 恐慌低点 → 154 箱体企稳、缩量至 1/8）表明第一次定价已经完成：卖方集体转谨慎（野村降中性 164、花旗降目标价 198 并预测全年营收 -8%），但没有一家给出卖出评级。

硬币的另一面是基本盘质量在变好——中国 +47.3%（线上 +62.7%）重新加速、IP 矩阵去单点化（LABUBU 38%→26%、星星人 +580% 且新品秒罄溢价 13 倍）、零负债 + 124 亿现金 + 17 亿回购，段永平 5.55% 的重仓仍在。消费端热度与股票端情绪的背离，是当前最值得注意的信号。

对投资者的核心追问是：14.5x PE 是否已把「增长换挡 + 海外失速」充分定价？多方看到的是「错杀」（中报利空两周消化完毕 + 内需加速 + IP 平台化 + 大户重仓）；空方看到的是「价值陷阱」（花旗 -8% 全年预测 + 利润增速 10% + 存货 201 天）。裁决权在 H2 的海外收入与存货两个数据上——在那之前，这是一只「赔率已改善、确定性待验证」的标的，而非「无脑捡便宜」。
