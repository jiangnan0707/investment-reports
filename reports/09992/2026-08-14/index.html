二、商业模式

泡泡玛特是一家以 IP 为核心、以盲盒/手办/毛绒为载体、全球化运营的潮流玩具公司。商业模式可拆为「上游 IP 孵化 → 中游产品化与供应链 → 下游全渠道销售 → 会员复购」四层。

怎么赚钱

  • 艺术家 IP 授权/买断：签约或买断艺术家 IP（如 LABUBU 作者龙家升、MOLLY 作者 Kenny Wong），占收入约 90%；
  • 产品化变现：把 IP 做成盲盒、手办、毛绒、积木等，盲盒 69–159 元/只的主流定价，毛利率 72.1%一手；
  • 渠道矩阵：线下直营店 + 机器人商店 + 线上（天猫/抖音/自研 App/海外 TikTok/Shopee/亚马逊）；
  • 会员体系：中国大陆注册会员 7258 万，会员贡献销售占比 93.7%，复购率 55.7%二手。

护城河（巴菲特式追问：竞争对手为什么无法复制？）

  • 无形资产/IP 资产库：17 个 IP 收入破亿、6 个 IP 破 20 亿，形成 IP 梯队而非单一依赖；但头部 IP 依赖仍高（详见核心指标章节）；
  • 艺术家生态：长期绑定头部艺术家，签约/买断模式锁定 IP 独家权，是「内容供给」的源头壁垒；
  • 全球化渠道先发：630 家门店 + 2637 台机器人商店，已进入 20+ 国家，形成物理网络密度；
  • 会员与复购：55.7% 复购率、93.7% 会员销售占比，是消费品牌稀缺的用户资产。
护城河的关键拷问：泡泡玛特到底是「能持续孵化爆款 IP 的平台」，还是「恰好押中了 LABUBU 这一只爆款的消费品公司」？这是本报告多空分歧的轴心（详见多空章节）。

三、核心指标 — IP 营收矩阵（LABUBU 等）

泡泡玛特唯一真正重要的指标是 IP 营收矩阵：头部 IP 的集中度、第二梯队 IP 的接力能力、以及单一爆款的生命周期，三者共同决定这家公司的估值是「成长股」还是「周期股」。

五、海外扩张深度拆解

海外是泡泡玛特过去两年的核心叙事：2024 年海外 50.7 亿（+375%）、占比 38.9%；2025 年海外 162.7 亿（+291.9%）、占比 43.8%。管理层的目标曾指向海外占比超 50%。

海外增速从「三位数」断崖式回落到「中高个位到五成」区间，是 2025 年报发布当天股价暴跌 22.51% 的直接导火索。市场担忧的核心不是「海外不行」，而是「高基数下的增速兑现节奏」——尤其美洲，从 1265% 回落到 55%，斜率过于陡峭。

汇丰（7/17）预测 2026 Q2 海外同比 -14%；德银（7/8）更悲观，预测 Q2 海外 -19%、全年收入 -6%。公司盈喜则暗示上半年收入增速至少 55%，与大行形成鲜明对立——8 月 19/20 日的中报是裁决时点。

六、IP 矩阵与生命周期（成长可持续性的费雪式检核）

费雪（Philip Fisher）的 15 要点中，最关键的几条拷问泡泡玛特：「公司是否具备高于平均水平的增长潜力，且这种增长是否可持续？」潮玩 IP 的生命周期普遍只有 2–5 年，这让「可持续性」成为比「当前增速」更本质的问题。

PE 历史分位（推算）

泡泡玛特 2020-12 上市，估值曾经历极端区间：2021 年首轮炒作冲高后跌至 2022 年低点；2025 年 6 月动态 PE 一度超 80x（股价高点 337 HKD 附近），随后业绩爆发 + 股价回落，PE 压缩至当前 14.5x。当前 14.5x 的 PE（TTM）处于公司上市以来的历史低位区间，对应 skill 中「14x PE 历史低位」的锚点。

PEG 的关键变量是「2026 增速到底是多少」：管理层指引「不低于 20%」，德银预测全年 -13%，分歧极大。若增速守住 20%+，14.5x PE 对应 PEG 0.73 属明显低估；若增速转负，14.5x 是「低 PE + 盈利顶点」的周期股陷阱信号（马克斯第二层思维）。

股息率 vs 融资利率（skill 关键原则）

泡泡玛特是成长股而非红利股：派息率仅 25%（且从 35% 下调），股息率约 0.4%~2%（口径不一，见下方说明），远低于 10 年期国债 ~2.8% 与港股融资利率 ~3.5%。「股息覆盖融资成本」的长期持有逻辑在此不成立，持仓逻辑完全依赖成长与估值修复，而非分红现金流。

⚠ 股息率口径矛盾：行情字段显示 0.41%，但 2025 末期息 2.3817 元/股（RMB）按现价折算应更高。差异可能源于末期息尚未除权入账或字段口径不同。时效 本报告不以此作为估值锚，仅作提示。

可比公司（谨慎参考）

港股最接近的潮玩/积木 IP 对标是 布鲁可（Bloks，0325.HK）（盲盒积木、IP 驱动），另可参考拥有 TOP TOY 的 名创优品（09896.HK）。但因商业模式与 IP 结构差异，跨公司直接对比倍数意义有限（skill：不做无关对比），此处仅列方向，不作机械套用。

多空核心分歧

多方逻辑

  • 护城河实化（巴菲特）：17 个 IP 破亿、6 个破 20 亿，艺术家生态 + 7258 万会员 + 55.7% 复购，是稀缺的 IP 平台资产，非「单只爆款」。
  • 全球化收获期：海外占比 43.8%，四大区域全数三位数增长，630 家门店全球网络形成物理壁垒。
  • 盈利质量高：毛利率 72.1% 堪比奢侈品，净利率 35%，规模效应释放。
  • 估值历史低位：PE 从 80x+ 压缩到 14.5x，若增速守 20%+，PEG 0.73 属明显低估（大摩「14x 2026 PE 被低估」）。
  • 新 IP 接力证据：星星人 +1602%、SKULLPANDA 35 亿，证明造星能力未失效。
  • 段永平态度反转：2026-03 收回「不投资」说法，实地考察后称「right business, right people, right price」。

空方逻辑

  • 单一 IP 依赖加剧：LABUBU 占比 23.3%→38.1% 不降反升，是集中度风险强化而非化解。
  • IP 生命周期短（2–5 年）：CRYBABY 增速 +1537%→+151% 断崖，星星人可能重演，潮玩难逃「热度见顶」。
  • 增长指引「急刹车」：2026 指引「不低于 20%」，从 184.7% 骤降，暗示高增长时代终结。
  • 海外增速断崖：美洲 Q3 +1265% → Q1 +55%，汇丰/德银预测 Q2 海外转负（-14%~-19%）。
  • 盈利质量隐忧：租赁 +192%、物流 +276% 的重资产扩张，销售费用 +121%，若销售转弱将侵蚀利润。
  • 段永平式「灵魂发问」：「万一过两年大家都不要了呢？」潮玩是情绪消费，护城河可能不如想象深。

核心争议焦点（一句话）

泡泡玛特是「能持续孵化爆款的 IP 平台公司」，还是「押中 LABUBU 一只爆款的周期性情绪消费公司」？

裁决指标（决定多空胜负的可观测变量）

  • 8/19–8/20 中报：Q2 海外增速是否守住正增长（vs 汇丰 -14% / 德银 -19%）；
  • LABUBU 占比是否回落：第二梯队 IP 是否真正接力（占比结构而非绝对额）；
  • LABUBU 二级市场溢价：限量款是否仍「抢购/溢价」，是热度最灵敏的温度计；
  • 非 LABUBU IP 增速：星星人、SKULLPANDA、CRYBABY 的持续性。

三大讨论焦点

  • 段永平态度反转：从「看不懂、不投资」（2025 底）→「万一过两年大家都不要了呢」（2026-01 灵魂发问）→「决定收回不投资的说法」（2026-03-30）→实地考察后「right business, right people, right price」「王宁比我强」。这一反转是雪球最热话题。
  • 「茅台批价」式见顶信号：投资者类比「飞天茅台 2016–2021 从 1200 涨到 3100 后涨不动，股价就见顶」，提出潮玩版的判据——「哪天 LABUBU 限量款不用抢了、卖不出溢价了，泡泡玛特股价也就到头了」。且潮玩升级换代更快，见顶可能来得更早。
  • 「爆款消费品」 vs 「IP 平台」的认知分歧：质疑方视其为爆款驱动的消费品公司、热度近峰值；支持方视其为可长期运营 IP 的平台公司，跨媒介/跨品类/跨场景是更稳的底盘。

反方声音（理性降温）

  • 有用户认为：即便 LABUBU 热度退散，运营积累的认知可通过授权、联名、乐园延续，无形价值未来或超玩偶销售本身。
  • 也有观点指出：市场认知迭代速度「赶不上泡泡玛特的增速」，股价与基本面的背离（业绩亮眼却暴跌）本身反映的是估值预期差，而非公司质变。
「泡泡玛特没变，资本先变脸了」——社区中这句被反复引用的话，恰点出当前阶段的核心：公司基本面仍在兑现，但市场对「增速可持续性」的定价发生了根本转向。

综合判断框架

综合巴菲特（护城河）、费雪（成长可持续性）、林奇（PEG/股票分类）、马克斯（第二层思维/周期）四套框架，泡泡玛特当前处于「从快速成长股向可持续成长股过渡」的十字路口，估值已从极端泡沫（80x+）压缩到历史低位区间（14.5x），但「低估值是否等于好价格」取决于增速能否守住的裁决。

总结

泡泡玛特是一家护城河真实存在（IP 资产库 + 艺术家生态 + 全球渠道 + 会员复购）但仍在「验证可持续性」的公司。2025 年 371 亿营收、72.1% 毛利率、14.5x PE 的组合，放在任何成长股框架下都值得严肃研究；但 LABUBU 单一依赖（38.1%）与海外增速断崖，构成真正的、尚未被证伪的长期风险。当前的核心矛盾不是「好不好」，而是「14x 的估值，是否已经 price in 了增速见顶」——这个问题的答案，将在 8 月中报与接下来 2–3 个季度的 IP 矩阵演化中揭晓。
